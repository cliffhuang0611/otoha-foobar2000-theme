IME limitation:
JSplitter's GDI-drawn search fields do not expose a native caret position to
Windows Japanese IME. Japanese text can still be entered and committed in the
inline field, but the preedit/candidate window may appear at the top left.
This is NOT fixed by scripting the fake caret. A true inline correction would
require JSplitter to expose Win32 caret/IME composition positioning (or a native
child edit control), or an optional separately maintained native helper.
No external programs or modal input dialogs are added in this build.
