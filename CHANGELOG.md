# Changelog

## 1.2.0

- Add drag-and-drop reordering of sidebar playlists, with an insertion marker, drag preview, and edge scrolling.
- Save the native playlist order and use the same order for Home playlist cards, keeping All Songs pinned.
- Keep playback references and navigation history aligned when playlist indexes change.

## 1.1.0

- Add drag-and-drop reordering of playlist tracks in Sort: Default.
- Move multiple selected tracks together, with an insertion marker and edge scrolling.
- Preserve duplicate entries and use native playlist moves without restarting playback.
- Disable internal reordering for sorted, filtered, and read-only playlists.
- Document saving the updated stored playlist order to M3U8 through Save playlist.

## 1.0.0

First Otoha release, based on Verdant by superziper.

- Introduce Otoha branding, a centralized Frosted Cyan palette, and updated screenshots.
- Expand library browsing, playlist editing, navigation history, and responsive layouts.
- Add persistent, editable Play order with multi-track selection and drag-and-drop.
- Add manual LRCLIB lookup, lyric editing, timestamps, and file/metadata saving.
- Remove the UI Wizard dependency and improve panel repainting in light mode.
- Document independent installation, removal, and reinstallation using Columns UI layouts.
- Make installer backups optional, with bounded retention; exclude core/component configuration snapshots from releases.
